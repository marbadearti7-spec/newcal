# newcal

# 🧮 Flask Calculator

A simple and responsive calculator built using **Python**, **Flask**, **HTML**, and **CSS**. This project performs basic arithmetic operations and is deployed online using Render.

## ⚙️ Installation

1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

2. Navigate to the project folder

```bash
cd calculator-project
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000
```
